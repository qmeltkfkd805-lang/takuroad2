## ✅ 이번 버전 확정 (결정 요약)
- 테마는 **보류**한다.
- `collection_key` 컬럼은 **지금 만들지 않는다** (컬렉션 UI가 필요해질 때 추가 · 이름은 확정).
- 레벨 전용 코스메틱은 **10~15개**부터 시작한다.
- **LV50·70·100을 먼저** 설계한다 (상징 + 칭호 + 연출).
- **봄(벚꽃)은 첫 레벨 컬렉션(봄의 기억)**으로 사용한다.
- **기본 획득 경로는 하나**를 원칙으로 한다 (이벤트 복각은 예외).
- **UI엔 장면 이름 + 진행도만** ("컬렉션" 단어 숨김), 내부 키는 **`collection_key`(내부 전용)** 하나.

## 🎯 LV50 / LV70 / LV100 — 상징 보상 먼저 (제일 중요)
> 이름보다 "획득 순간"을 먼저. 상징 + 칭호 + 연출을 묶고, **컬렉션 밖 단품**으로 둔다.

| 레벨 | 상징 보상 | 칭호 | 연출 |
|---|---|---|---|
| LV50 | 황금 나침반 | 여행의 달인 | 레벨업 특별 연출 |
| LV70 | 왕관 효과 | 덕질 황제 | 레벨업 특별 연출 |
| LV100 | TAKU MASTER 오라 | TAKU MASTER | 최상위 전용 연출 |

> **획득 경험까지 같이 설계** — 레벨업 모달이 중요한 UX라, 아이템마다 "어떻게 나타날까?"를 정한다. **연출만이 아니라 애니메이션·사운드·햅틱·모달 전부 포함.**
> 예) 황금 나침반: **레벨업 → 나침반 회전 → 빛 → 사운드 → 획득.**
>
> 획득 경험은 **코스메틱의 중요도에 따라 차등 설계**한다 (LV50 정점뿐 아니라 중요 코스메틱 전체). **구체적인 연출(애니메이션·사운드·햅틱·모달)은 구현 단계에서 결정**한다 — 웹에 햅틱이 없어도 문서를 안 고쳐도 되게.

## 이번에 만들 것 (총 10~15개 — 여백 남기기)
- **봄의 기억 4** (배경·효과·프레임 = 이미 있음 / **칭호만 신규**)
- **밤열차 4** (전부 신규)
- **LV50/70/100 정점 3** (황금 나침반 · 왕관 효과 · TAKU MASTER 오라 + 각 칭호)

> 레벨 보상은 계속 추가 가능 → 지금 다 채우지 말 것.

## 컬렉션 제작 원칙 (현재 4축)
한 컬렉션 = 하나의 장면. 각 아이템 종류가 장면에서 맡는 역할:
- 배경 = **공간**
- 효과 = **분위기**
- 프레임 = **기억**
- 칭호 = **그 여행을 마친 흔적**

→ 한 컬렉션 안의 모든 아이템은 **같은 장면·같은 감정**을 공유. 예) 봄의 기억 — 배경=벚꽃길 · 효과=꽃잎 · 프레임=벚꽃 · 칭호=봄을 지나온 사람.

컬렉션은 현재 **배경·효과·프레임·칭호 4축**으로 구성한다. 필요하면 새로운 종류를 추가할 수 있다(예: 프로필 장식).
**컬렉션의 기준은 아이템 종류가 아니라 장면과 감정이다.**

## 현재 제작 예정 (확정 아님 · 예시)

### 🌸 봄의 기억 (벚꽃) · 감정: 설렘 — 칭호만 신규
| 슬롯 | 아이템 | 등급 | 상태 |
|---|---|---|---|
| 배경 | 벚꽃 (벚꽃길) | epic | ✅ 있음(미획득) |
| 효과 | 벚꽃 흩날림 (꽃잎) | epic | ✅ 있음(미획득) |
| 프레임 | 벚꽃 프레임 | legendary | ✅ 있음(미획득) |
| 칭호 | **봄을 지나온 사람** (후보: 꽃잎을 품은 날 · 벚꽃 아래에서) | rare | 🆕 |

### 🌌 밤열차 · 감정: 낭만 — 전부 신규
> UI 이름은 장면형으로 확정 예정 (후보: **별빛 종착역** · 마지막 열차 · 새벽 승강장 · 종착역의 밤).
| 슬롯 | 아이템(예) | 등급 | 상태 |
|---|---|---|---|
| 배경 | 밤열차 창밖 (별·야경) | epic | 🆕 |
| 효과 | 차창 불빛 (느린 반짝임) | epic | 🆕 |
| 프레임 | 승차권 프레임 | legendary | 🆕 |
| 칭호 | **새벽 플랫폼** (후보: 마지막 승차권 · 별빛 종착역) | rare | 🆕 |

여권 · 스탬프 · 나침반 · 승차권 · 비행기 · 지도 · 캐리어 · 여행가방 · 열차 · 밤열차

## 지금은 구조 변경 없음
- **컬렉션 UI(진행도/완성)가 필요해질 때 `collection_key` 컬럼을 추가한다.**
- 내부 키 이름은 그때 `collection_key`를 사용한다. (이름은 정했고, 컬럼만 아직 안 만듦)
- **출처는 파생** — 기본=`is_default` / 배지=`reward_cosmetic_id` / **레벨 전용=배지 없음 + `level_rewards`(P5)** / 시즌·이벤트=나중에.
- **레벨 전용은 신규 slug로 제작** (기존 테마 아이템은 배지 해금이라 출처 충돌).
- 프로필 장식 새 타입도 지금은 안 만듦 (나중 확장 포인트).

## 우선순위
1. ✅ 테마 보류
2. ✅ 봄의 기억 제작 (칭호만 신규)
3. ✅ 레벨 전용 코스메틱 10~15개
4. ✅ **LV50 / LV70 / LV100 핵심 보상 먼저 확정**
5. ✅ 이후 필요하면 밤열차 외 신규 컬렉션/시즌/이벤트 추가

① 감정 결정 → ② 장면 이름 결정 → ③ 배경 → ④ 효과 → ⑤ 프레임 → ⑥ 칭호 → ⑦ 획득 경험 설계 → ⑧ 레벨 배치
→ 새 컬렉션마다 **항상 같은 방식**으로 만든다. (감정부터 시작 = 철학 §3)
